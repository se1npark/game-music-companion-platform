# Portfolio Strategy

## Resume Line

Built a full-stack game and music companion platform that recommends playlists based on game genre, player mood, and session context using React, Node.js, PostgreSQL-ready data modelling, external API integration planning, and explainable AI-style recommendation logic.

## Interview Pitch

I wanted a project that connects my interests in games and music with practical full-stack engineering. The app lets a player enter a prompt like "I'm playing Valorant tonight and want dark, intense music", then the backend analyses the game profile, mood, time of day, and session style to return a playlist with an explanation. The current version runs with seeded data, but it is structured for Spotify, Steam, RAWG, OpenAI, and PostgreSQL/Supabase.

## Skills Demonstrated

- React and TypeScript dashboard development.
- REST API design with Express and Zod validation.
- Database modelling for users, games, tracks, playlists, and third-party service connections.
- External API architecture for OAuth and provider-specific metadata.
- AI workflow design with explainable outputs and future RAG scope.
- Docker and GitHub Actions basics.
